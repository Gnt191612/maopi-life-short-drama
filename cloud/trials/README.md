# 试片过程脚本（11-27 H3 方案试片的实际执行记录）

这些是 11-27 在仙宫云 TDTJ 实例上试片时临时排队用的脚本，**不是正式流程**，留作记录，方便以后照着排对比试验：

| 脚本 | 做什么 |
|---|---|
| trial_pika.sh | 用户认定 Pika 质感更好后，停掉 20 步队列，只验证 Pika + 新提示词（三镜头、深度 0.6、原生语音、MOSS、口型） |
| trial_20step.sh / trial_reorder.sh | 用户要求看到两方案完整片段再判断：20 步版用新提示词重跑同样三镜头，排到最前 |
| trial_strength.sh | 控制强度测试：Pika 版 0260 用官方默认 pose 1.0 + depth 1.0，看构图是否跟住白模 |
| trial_extra.sh | 早期追加对照（已被上面的脚本取代） |

正式流程：试片用 `cloud/trial_h3.ps1`，全片用 `cloud/full_fun.ps1`。
排队经验：ComfyUI 本身按顺序执行提交的任务，所以多个脚本同时提交不会抢显卡，只会排队；要改顺序就等当前这条跑完再接（见 trial_reorder.sh 用 PID 等待）。
