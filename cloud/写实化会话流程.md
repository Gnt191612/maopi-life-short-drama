# 写实化会话流程（2026-11-22 起）

原则：**凡是不需要云端显卡的事都在本地提前做完**；实例开机后只跑写实化，跑完马上下载、关机。

## 一次成片（2026-11-22 起推荐）

1. 本地：`cloud\prep_trial.ps1 -SkipCast -Segs <全部 27 段>`（重拍全片 + 高清首帧 + 打包）
2. 开实例 → `cloud\session.ps1 -SshHost … -Port … -Stage final -MaxHours <预算小时数>`
   - 片头：Claude 娘竖屏 720×1280 重新生成（首帧 = 原立绘，扇子全程合着），解决放大模糊
   - 全片关键帧（外景重绘力度大；看不到脸的镜头不换脸）→ 全片视频
   - `-MaxHours` 到点强制停、下载已有结果（预算保护，防止欠费）
3. 关机 → 本地 `cloud\make_final.ps1 -Result build\cloud_out\final_<时间>` → `build\final\毛坯人生，精装朋友圈_成片.mp4`

## 本地准备（不花钱，提前做）

```powershell
powershell -ExecutionPolicy Bypass -File cloud\prep_trial.ps1            # 默认试片 = 第 3 场（林晓宿舍 + 林母在家，约 35 秒）
```
1. 七个角色按定稿流程重建到 `assets\cast`（建模 + 贴标准长相照片）
2. 用新角色重拍、重渲试片片段（EEVEE 预览画质，白模 + 深度）
3. 导出骨架、按镜头打包 → `dist\cloud_pack.zip`（只带出场角色的标准长相 JPG、每个镜头首帧，约 12 MB）

## 云端（写实化实例：Krea2 镜像 + 4090D，约 ¥1.89/时）

每一步都是同一条命令，只换 `-Stage`；脚本会上传、后台运行、盯进度、下载结果，结束时打印本次花费并提醒关机。
卡住 20 分钟没进展会自动中止并下载已有结果。

| 顺序 | 命令 | 做什么 | 预计 |
|---|---|---|---|
| 1 | `-Stage probe` | 列出镜像里的工作流、节点、模型 → `probe.txt` | 1 分钟 |
| 2 | （本地）| 照 `probe.txt` 填 `cloud\video_map.json`（视频工作流的首帧/提示词/帧数/种子节点） | 5 分钟 |
| 3 | `-Stage test` | 第一个镜头：写实关键帧 + 视频第一段 | 5~10 分钟 |
| 4 | （本地看效果）| 不满意就调 `looks.py` / `video_map.json`，重跑 test | — |
| 5 | `-Stage all` | 全部镜头：关键帧 + 视频 | 试片 35 秒约 1~1.5 小时 |

```powershell
powershell -ExecutionPolicy Bypass -File cloud\session.ps1 -SshHost root@<主机> -Port <端口> -Stage probe
```
连接地址在仙宫云控制台「SSH」里看（每次开机可能变）；密钥用本机 `~/.ssh/xiangongyun_ed25519`（控制台登记名 v11）。

结果下载到 `build\cloud_out\<阶段>_<时间>\`：`kf\`（每个镜头写实关键帧）、`real\<任务id>\frame_####.png` 与 `.mp4`。
合成成片：`python run_all.py --previs-only --real=build\cloud_out\<目录>\real`（输出 `build\final\`，缺的帧用白模补）。

## 花费估算（4090D ¥1.89/时）

- 关键帧：约 1~2 分钟/镜头（二转三 + 每个出场角色一次人物替换）
- 视频：Wan2.2 类图生视频 832×480、81 帧（约 5 秒）一段约 4~8 分钟；试片 10 个镜头，超过 5 秒的镜头拆两段，共约 12~14 段
- 试片总计约 1~1.5 小时 ≈ ¥2~3；开机等待（1TB 盘约 10~15 分钟）另计

## 规矩

- 开机前、跑完后都看一眼余额；**充值必须先问用户**，绝不欠费
- 一个阶段跑完、下一阶段不是马上要跑 → **立刻关机**（只释放 GPU，磁盘保留）
- 平台已设全局规则：GPU 闲置 30 分钟自动关机（兜底，不要依赖）

## 脚本一览

| 文件 | 在哪跑 | 作用 |
|---|---|---|
| `prep_trial.ps1` | 本地 | 重建角色 → 重渲试片 → 打包 |

| `session.ps1` | 本地 | 上传、后台运行、盯进度、下载、报花费 |
| `session_realism.sh` | 云端 | 总控：解包、确认 ComfyUI、按阶段运行（带超时）、打包结果 |
| `probe_comfy.py` | 云端 | 摸清工作流节点与模型 |
| `keyframes.py` | 云端 | 首帧白模 → 二转三 → 逐个角色人物替换（已验证做法） |
| `video_run.py` | 云端 | 关键帧 → 图生视频（分段续接、可加深度/骨架控制）→ 24fps 帧序列 |
| `comfy_run.py` | 云端 | ComfyUI 界面工作流转 API 并排队（图片、视频结果都能取回） |
| `make_final.ps1` | 本地 | 拆帧 → 片头（高清 Claude 娘）→ 正片合成 → 片头+正片成片 |

| `looks.py` | 两边 | 角色外貌描述（中/英），与定稿白模一致 |
| `video_map.json` | 两边 | 视频工作流的节点映射（probe 后填） |
