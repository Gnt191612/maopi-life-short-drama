# 用这套管线制作新短剧

整条管线是数据驱动的：换剧本、换角色、换场景，主要改 `story/` 和几个字典，代码基本不用动。

## 1. 剧本 → 拍摄表（`story/`）

| 文件 | 写什么 |
|---|---|
| `剧本_修订版.md` | 人读的剧本（不参与运行） |
| `lines.py` | 台词表 `LINES`：`(台词ID, 角色, 台词, 语气说明)`；手机屏幕文字 `SCREEN` |
| `story_scenes.py` | 分场拍摄表：每场一组「拍」`b(拍ID, 机位方式, [出场角色], en=英文画面描述, act=中文动作, line=[台词ID], sfx=…)` |
| `blocking.py` | 走位（每场角色站位、移动） |
| `music.py` | 配乐表 `CUES`：从哪拍到哪拍、哪首曲子、音量 |

- `en=` 的英文描述同时决定**景别**（extreme close-up / close-up / medium close-up / wide）和写实化提示词，写清「几个人、在哪、在做什么」。
- 机位方式：`new`（新机位）、`cut`（切）、`cont`（延续）、`est`（空镜）。
- 导演原则：不用旁白；网络评论、来电等放手机屏幕。

## 2. 角色

1. `blender/build_cast.py`：`CAST`（姓名、性别、身高等宏参数、基础服装）、`HEIGHT`、`FACE`、`EYEBROW`、`SKIN_TINT`、`OUTFIT`、`SHOES`。
2. 仓库根目录 `segments.py` 里的 `CID`：中文名 → 角色代号。
3. 按 [人物定妆与建模.md](人物定妆与建模.md) 定长相、拟合、贴脸、做头发和服装。
4. `cloud/looks.py`：外貌描述（中/英），要和定稿白模一致。

## 3. 配音

```powershell
# Spark-TTS 设计音色（voice_tools/voice_design.py 的 ROLES 加角色：性别、音高/语速组合、参考句）
.tools\sparkenv\Scripts\python voice_tools\voice_design.py     # 环境由 setup\setup_tts_windows.ps1 安装
python voice_tools\voice_pick2.py                    # 自动打分挑音色 → voices_v2/pick.json（也可人工指定）
.tools\index-tts\.venv\Scripts\python voice_tools\tts11.py   # IndexTTS2 按「语气说明」逐句配音 → assets/audio
```
复合情绪（阴阳怪气、强装轻松）在 `tts11.py` 的 `EMO_OVERRIDE` 手定；性格幅度 `ROLE_ALPHA`。

## 4. 场景

`blender/build_sets.py` + `blender/lib/sets.py`、`outdoor.py`：按真实尺寸程序化搭建。场景名在拍摄表的 `sc=` 里引用。

## 5. 拍摄、写实化、成片

```powershell
$env:V11_PREVIEW='1'; python run_all.py                                   # 白模预演，人看剧情、走位、节奏
powershell -ExecutionPolicy Bypass -File cloud\prep_trial.ps1 -Segs <全部片段>   # 定稿角色 → 重拍 → 打包
# 云端：probe（新镜像先探查，填 cloud/video_map.json）→ test（看一个镜头）→ final
powershell -ExecutionPolicy Bypass -File cloud\make_final.ps1 -Result build\cloud_out\final_<时间>
```

## 6. 片头

`blender/intro_compose.py` 顶部的常量：背景照片、校徽、角色视频、配音、片名、队长、队员、仓库地址。
角色动作在云端用绿幕生成（`cloud/intro_video.py`，竖屏 720×1280 才清晰），配音用 `voice_tools/claude_voice.py` + `claude_line.py`。

## 7. 时间与花费参考（v11，4090D ¥1.89/时）

| 环节 | 速度 |
|---|---|
| 本地白模预演（EEVEE，8GB 显卡） | 全片约 2~3 小时 |
| 云端开机（该镜像 1TB） | 10~15 分钟 |
| 写实关键帧 | 1~2 分钟/镜头 |
| 图生视频 832×480，81 帧一段（约 5 秒） | 3~4 分钟/段 |
| 10 分钟成片 | 约 140 个镜头、130 段视频 → 云端约 10~12 小时 |
