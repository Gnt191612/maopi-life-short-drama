# 人物定妆与建模流程

原则：**先定长相，再照着照片建模**。不要直接手调形态参数去猜「好看」，效率极低。

## 0. 定长相（每个角色一次）

1. 本地先建一个大致符合人设的白模（`blender/build_cast.py` 的 `CAST`、`FACE`、`OUTFIT` 里加角色）。
2. 云端 Krea2「二转三」把白模正脸转成写实照，每人换几个种子出候选（`cloud/candidates.py`，外貌描述在 `cloud/looks.py`）。
   用户也可以给参考图定方向（只参考气质、发型、服装，**不照着真人的脸做**）。
3. 用户挑一张 → 存为 `assets/identity/<cid>.png`（正脸、五官清楚，1456×1456 左右）。

## 1. 关键点标注 `assets/identity/<cid>_landmarks_full.json`

像素坐标 `[x, y]`；`R/L` = 角色自己的右/左（照片左边是 R）。`contour_*`、`skull_*` 写成 `[y, x]`。

| 键 | 含义 |
|---|---|
| `eye_R_out/in/top/bot`，`eye_L_*`，`eye_R`/`eye_L` | 眼角、上下睑、瞳孔中心 |
| `nose` `ala_R/L` `subnasal` | 鼻尖、鼻翼外缘、鼻底 |
| `mouth_R/L` `lip_top` `lip_bot` `chin` | 嘴角、上下唇中点、下巴尖 |
| `contour_R/L` | 脸颊外轮廓（按高度取 5 点） |
| `skull_R/L` `skull_top` | 头骨外轮廓（按头发外缘估，权重低） |
| `hairline` | **看得见的头发边缘**（含刘海；不要标在外缘稀疏细发上） |
| `skin_top` | 照片露皮肤的上边界（贴脸只用它以下；碎发、刘海盖住额头时比 hairline 低） |

标完用叠加图检查（各点画在照片上）。只放 `[x,y]` 点，**不要混进别的数据**（会让拟合静默失败）。

## 2. 脸型拟合

```powershell
.tools\blender\blender.exe -b --factory-startup -P blender\face_fit_export.py -- <cid> build\face_fit\<cid>_head.npz
python blender\face_fit_solve.py <cid>
copy build\face_fit\<cid>_fit.json assets\identity\<cid>_face_fit.json
```
看 `err_after`（眼距的比例，男生们 0.04~0.065 为正常）和叠加图 `build/face_fit/<cid>_fit_overlay.png`。

拟合只看正面轮廓，深度方向（胖瘦、双下巴、嘴突）要在 `build_cast.py` 的 `FIT_ADJUST[cid]` 手补；
局部修形：`FIT_SMOOTH`（磨平褶）、`FIT_CROWN`（压低头顶）、`FIT_SHOULDER`、`LIP_SEAL`（**新角色一定加进去**）。

## 3. 一轮精修

```powershell
powershell -ExecutionPolicy Bypass -File blender\tests\identity_round.ps1 -Cid <cid> -Tag <轮次> [-Back] [-Body] [-CamDz -0.04]
```
建模（试验目录 `build/face_fit/cast`）→ `face_project.py` 贴照片 → 对比图。每轮改一两处，对比图给人看，按意见再改。

## 4. 头发 `blender/lib/hair_cards.py` 的 `CARDS[cid]`

- `style='ponytail'`（同学乙）/ `'short'`（男生）/ `'long'`（披肩，已写未启用）
- 发际线按照片 `hairline` 投影；`hl_drop` 整体下移；`base_hl`（两侧/耳后/后颈相对眼高）；`whorl`/`sink` 发流方向
- 碎发：`fringe`（碎刘海）、`tufts`（蓬松簇）、`baby`（胎毛）、`fly`（飞发）、`frame`（脸侧碎发）
- 用社区发型做轮廓：`HAIR_SHAPE[cid]`；认可的就是轮廓本身时加 `KEEP_SHELL`（不再沿它长发丝）

## 5. 身体与服装

- 身材：`BODY[cid]`（只用身体形态目标，不动宏「体重」，否则脸型拟合失效）、`CUP`/`FIRM`；腿加长靠 `ground_body` 抬回地面
- 服装：`OUTFIT[cid]`（MakeHuman 社区服装 + `jk_retex` 改色）；合身：`TOP_FIT`、`shorten_top`、`push_out`、`hide_under`
- 没有合适素材就从身体表面长：`blender/lib/jk_sailor.py`（`SAILOR` 水手服、`VTOP` V 领上衣，含宽松、续布）
- 饰品：`blender/lib/accessories.py`（`EARRING`，只戴在露出来的耳朵上）
- 检查：`identity_round.ps1 -Body`（正/3/4/侧/背，带衣服和不带衣服两套）

## 6. 定稿

```powershell
powershell -ExecutionPolicy Bypass -File cloud\prep_trial.ps1 -Cast <cid> -Segs <要重拍的片段>
```
重建到正式目录 `assets/cast` → 重拍 → 打包。发布前 `setup\pack_assets.ps1 -Version vX.Y` 更新 Release。

各问题的具体解决办法见 [踩坑记录.md](踩坑记录.md) 第二~四节。
