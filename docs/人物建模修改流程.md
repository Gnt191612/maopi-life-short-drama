# 人物建模修改流程（给协作的 AI 会话看）

项目根目录：`D:\v11`。7 个人物由 Blender 4.5 脚本自动生成（MPFB 2 / MakeHuman 素材），**不要手工改 .blend**，重建会覆盖。

## 循环
1. 用户提修改意见（可能附带审阅器里的「打点意见」，格式为 角色 + 部位 + 意见）。
2. 修改对应脚本（见下表）。
3. 运行一键更新，把最新模型展示在审阅器里：
   ```
   powershell -ExecutionPolicy Bypass -File D:\v11\viewer\更新模型.ps1 <角色代号 ...>
   ```
   不带代号 = 全部重建（较慢）；只改了导出脚本时加 `-NoBuild`。审阅器已打开时按 F5 刷新。
   **用户要求以后重建都用云端**（快 5 倍、不占用户电脑）：在仙宫云控制台开机（实例 BX1D…，基础镜像，环境已装好），
   从控制台「SSH」看连接地址，然后：
   ```
   powershell -ExecutionPolicy Bypass -File D:\v11\cloud\rebuild_remote.ps1 -SshHost root@<主机> -Port <端口> -Export <角色代号 ...>
   ```
   7 人并行重建约 1 分钟，检查图约 1.5 分钟，下载另计。**用完立刻关机**；账户已设「GPU 闲置 30 分钟自动关机」兜底；开机前看余额，绝不欠费。
4. 告诉用户改了什么，等下一轮意见。

## 改哪里
| 要改的内容 | 文件 | 关键位置 |
|---|---|---|
| 年龄、身高、胖瘦、肌肉 | `blender/build_cast.py` | `CAST` |
| 脸型、五官 | `blender/build_cast.py` | `FACE`、`FACE_SCALE_OF`、`DEPTH_M/DEPTH_F` |
| 肤色、眉毛款式 | `blender/build_cast.py` | `WARM`、`EYEBROW` |
| 衣服、鞋、黑丝 | `blender/build_cast.py` | 服装表、`SHOES`、`STOCKINGS`、`cloth_volume` |
| 短发（浓密、贴头皮、蓬松） | `blender/lib/hair.py` | `SHORT`（lift / n / messy / melanin）、`build_short` |
| 马尾、波波头 | `blender/lib/hair.py` | `STYLE`、马尾发圈部分 |
| 皮肤 / 眼睛 / 布料质感 | `blender/lib/realism.py` | `skin()`、`eyes()`、`cloth()` |
| 审阅器里的站姿 | `blender/lib/poses.py` | `apply_state`（站姿 base='stand'） |
| 导出效果（发丝粗细、眼睛、眉毛透明） | `blender/export_viewer.py` | |

## 产物位置
- 人物模型：`D:\v11\assets\cast_next\<代号>.blend`（暂存版，用户定稿后才替换正式版 `assets/cast/`）
- 审阅器模型：`D:\v11\viewer\models\<代号>.js`
- 审阅器：`D:\v11\viewer\启动人物审阅.bat`

## 规矩
- 不要 `git push`，不要动 `assets/cast/`（正式版）。
- 不要读取或打印任何 `.env`、令牌、密码文件。
- 用中文和用户交流。
- 报错时先看 `更新模型.ps1` 输出里的 Python Traceback。
