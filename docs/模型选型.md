# 模型选型（2026-11-27 定）

> 以后每次开工前都要按这里的方法**重新查一遍当时最新的模型**，不许直接沿用。理由和教训见[踩坑记录](踩坑记录.md)第 58～60 条、[避坑清单](写实化视频避坑清单.md)顶部的硬性规定。

## 一、为什么换

| 版本 | 视频模型 | 做法 | 结果 |
|---|---|---|---|
| 11-10 第一版 | Seedance 2.5（商业，榜单第 2） | 每个镜头凭一段文字单独生成 | 逻辑极差、反复慢放 |
| 11-11～12 v5～v9 | 阿里云百炼通义万相（wan2.5-i2v-preview 等） | 每个镜头凭一张图单独生成 | 像动态幻灯片；免费额度用完后悄悄扣费导致欠费 |
| 11-26 v11 | Wan2.2 Remix i2v 3.0（社区镜像自带） | 写实首帧 + 每 2～4 秒一张锚点图，**没有白模动作控制** | 动作飘忽、口型和配音对不上（49 个说话镜头只有 2 个合格），判定严重失误 |

共同的根源：**视频没有被白模的动作逐帧约束**，模型再强也救不回来。

## 二、现在的选择

| 环节 | 选用 | 理由 | 备选 |
|---|---|---|---|
| 写实首帧 | Krea2「二转三」（镜像自带） | 首帧质量 11-26 版已验证合格 | MiniMax H3-Image（同门图片模型，开机时对比） |
| **视频** | **MiniMax H3 首帧模式（fl2va）+ Fun ControlNet Union 2.0**（ComfyUI < 0.38 时用 1.0） | 2026-11 Artificial Analysis 图生视频榜上**开放权重第一**（第 7 名，1135 分，和 Seedance 2.0 / 可灵 4.0 同档；更高的全是闭源，任何租用显卡都跑不了）；官方支持姿态/深度控制视频逐帧驱动；原生 24fps、单段最长约 15 秒；镜像里就有 | H3 参考图模式（ref2va）；+ Pika H3 Flex 真实感 LoRA（试跑对比）；Wan2.2 Fun Control（上一代，H3 不行时才用） |
| 控制 | 白模姿态骨架 0.7 + 白模深度 0.3 | 网上实测：只用深度人物会往镜头方向漂，姿态更能钉住位置；两路都开满会糊 | — |
| 口型 | LatentSync 1.6（字节开源） | 按真实配音重画嘴型；成片前用 `cloud/av_sync_check.py` 客观验收 | H3 原生语音（声音和口型一起生成，中文效果待测） |
| **配音** | 待试跑对比定：**MOSS-TTSD v1.0**（复旦等开源，8B） | 专门做多人对话，一次生成整段，有对话的节奏和语气承接，官方主观评测胜过豆包、Gemini 2.5 Pro；免费可商用；要约 26GB 显存，在云端跑 | MiniMax Speech 2.8 HD（商业，全剧约 ¥1，需用户自己开通并设消费上限）；IndexTTS 2.5（本机可跑，提升有限）；现用 IndexTTS2 |
| 提示词 | 按 MiniMax 官方写作规范生成（`cloud/h3_prompt.py`），全片资产见 [prompts/](prompts/README.md) | 官方：首帧对齐句 + 三字段、运镜三要素、正面描述、不写负面 | — |
| 换脸统一 | InsightFace inswapper + GFPGAN（本机） | 多人镜头云端不换脸（Qwen 会连衣服一起换、选错人）；五官定位点做前后帧平滑去抖 | — |

许可：MiniMax H3 商业使用要另购授权，本项目是思政课作业、不商用。

## 三、怎么跑

```powershell
# 开机后先看磁盘和镜像里的 H3（只看不删）
powershell -ExecutionPolicy Bypass -File cloud\trial_h3.ps1 -Step report
# 试跑：3 个代表镜头 + turbo / 参考配音 / 原生语音对照 + 口型 + MOSS-TTSD 对话配音 → build\review\trial_compare\
powershell -ExecutionPolicy Bypass -File cloud\trial_h3.ps1 -Step trial
# 用户确认合格后全片（默认 H3；断线或空闲关机后重跑会接着做）
powershell -ExecutionPolicy Bypass -File cloud\full_fun.ps1 -Step start
powershell -ExecutionPolicy Bypass -File cloud\full_fun.ps1 -Step pull     # 后台，边跑边取回替换
powershell -ExecutionPolicy Bypass -File cloud\full_fun.ps1 -Step final    # 合成 + 审查（跑偏、角色、台词对齐、音画同步）
```

相关文件：`cloud/video_h3.py`、`cloud/setup_h3.sh`、`cloud/wf_templates/`（ComfyUI 官方 H3 模板原件）、`cloud/lipsync.sh`、`cloud/tts_moss.py`、`cloud/setup_moss.sh`、`cloud/av_sync_check.py`、`cloud/dialog_audit.py`、`cloud/cast_sheet.py`。

## 四、下次重新选型的方法

1. 看盲测榜单（Artificial Analysis 视频榜、TTS Arena），筛出**开放权重**的前几名；闭源的只能付费调用，先算钱。
2. 查 ComfyUI 官方文档有没有对应的**控制视频**工作流（姿态/深度），没有的不考虑。
3. 看仙宫云镜像市场有没有现成镜像（模型越新，带它的镜像越多）。
4. 开机先试 3 个代表镜头，新旧并排给用户看，确认后再报全片花费。
